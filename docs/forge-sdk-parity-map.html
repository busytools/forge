What's actually left seventh-pass update

Four of the five gaps flagged in the prior pass are now closed. Only one remains, blocked on upstream. Closed items stay listed (struck-through style) so the history is visible.

✓ SessionSummaryEntry + fold_session_summary session_summary.py

Closed on 2026-04-22 (seventh pass). Ported as src/session/summary.rs. Public re-exports: SessionSummaryEntry, fold_session_summary, summary_entry_to_sdk_info. Added SessionStore::list_session_summaries optional trait method (default NotImplemented).

Impact: third-party store authors can now maintain incremental summaries with the same fold function Python uses. 14 inline unit tests cover the invariants.

✓ run_session_store_conformance harness testing/session_store_conformance.py

Closed on 2026-04-22 (seventh pass). Ported as src/testing.rs. 14 contracts encoded; auto-probe for optional methods. Caught a real bug in MemorySessionStore::list_subkeys (subpath sanitisation leak) — fixed as part of the round.

Impact: third-party store adapters now have a public harness to certify against. The 5 previously-ignored TestInMemorySessionStore parity tests now run.

✓ Public Transport trait _internal/transport/__init__.py

Closed on 2026-04-22 (seventh pass). Carved pub trait Transport out of Subprocess. Client now uses Box<dyn Transport>; new Client::spawn_with_transport constructor for injection. Breaking change justified pre-release.

Impact: users can now inject in-memory mocks, remote-SSH transports, or containerised spawn. Foundation for downstream extensibility.

✓ query() as a Stream query.py — AsyncIterator[Message]

Closed on 2026-04-22 (seventh pass). Added query_stream() returning impl Stream<Item = Result<Message>> alongside the existing Vec- collecting query(). Spawned-task driver with consumer-drop cleanup.

Impact: callers can now consume messages as they arrive, matching Python's AsyncIterator ergonomics. Adds tokio-stream dep.

AsyncHookJSONOutput delivery types.py: AsyncHookJSONOutput

A hook can ACK asynchronously with {"async": true, "asyncTimeout": ms} and later deliver the real response out-of-band. forge-sdk emits the ACK frame; the follow-up channel isn't wired because upstream hasn't finalised its end of the protocol either.

Impact: deferred hooks can't yet deliver a real response. Blocked on upstream — revisit when Anthropic's Python side lands.

Notices

The scrollback is the only error surface. A notice carries the severity word in bold over body lines tinted to match, hard-wrapped.
Error
Connection failed: claude binary not found at /usr/local/bin/claude
Input disabled after an error. Press Ctrl+Q to quit and try again.
The input goes read-only rather than being replaced.
Warning
Failed to parse ~/.claude/settings.json: expected `,` at line 42 column 5. Falling back to defaults.
Deduplicated per file per parse attempt.
Warning
Near rate-limit threshold. Resets in 4h 23m at 14:30 UTC.
The same message tints the rate-limit chip on the assistant's reply.
Info
Mode changed: default → acceptEdits
Severity word dim, body dim.
✗ ⬚ crates/forge-tui/src/missing.rs │ File not found: crates/forge-tui/src/missing.rs └─ error path: open() returned ENOENT
✗ ▶ cargo build --release └─ error: failed to compile due to 3 errors
✗ ⬚ crates/forge-tui/src/something.rs │ Internal Agent SDK error └─ stream closed at offset 12483 mid-frame
A failed tool call renders the red cross with its body in red; for Bash only the first non-empty stderr line shows. Internal failures wear a bold red header over a red summary instead.

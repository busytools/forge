The section keys on the subscriptions alone, never on the pumps: a workspace whose pump drops keeps its rows and swaps the glyph. A conversation whose name was never captured renders its raw id unprefixed, because an id is not a name and a `#` would invent a channel.
What a mention subscription reaches, measured against a real workspace: a mention in a public channel the user has not joined is reachable; a private channel the user is not in is not, matching the user's own view. Search indexing lags about 16 seconds, so a mention is not instantaneous, and a message the user authored is never delivered, or an agent answering in Slack would answer itself.
A delivered message, as the session's chat renders it: one block per conversation sweep, oldest first, with a thread's replies under their parent.

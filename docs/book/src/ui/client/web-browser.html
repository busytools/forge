The browser surface

The server's Chromium as a full-window takeover: the page fills the window under a slim client bar, and the bar carries the hand-off's actions and the profile's tab picker. No window, no browser tab strip and no browser chrome - the page is the surface. A hand-off's Open and the strip's browser row both open it; the sessions drive the same tabs while it is closed.

the terminal surface

One terminal per seat, in the server process. The bar names the terminal, its shell and its cwd, and carries the state in words. The screen is the server's own grid, repainted as a VT stream on attach and then fed the shell's bytes.

the touch key bar is drawn under pointer: coarse: a finger cannot produce Escape, Tab or an arrow, and every key is a 44px target. Ctrl and Alt are sticky for the next character the soft keyboard types, and the whole bar is inert outside the person's own control: the surface is a viewer then, and the server refuses a keystroke that arrives anyway. A parked hand-off raises the surface as a viewer too - take control there to type.

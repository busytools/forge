# API reference

Every crate in the workspace is published as rustdoc at
[the API reference](./rustdoc/), private items included. It is the place to
go when you are reading or changing the code rather than running it.

This page exists so the link is in the sidebar on every page: `mdbook`
treats every `SUMMARY.md` entry as a chapter file under `src/`, so a sidebar
row cannot point at the site's own `/rustdoc/` directory directly.
